01 · Overview

One resource, several views of cardiac regeneration

MCAREDB connects single-cell expression, differential expression, chromatin-associated tracks, spatial transcriptomics, and pathway enrichment. Each page answers a different part of the same question: what changes after cardiac injury, in which cells, and where does it happen?

Cell identityCompare annotated cardiac cell populations and subclusters.
Molecular responseInspect expression and injury-associated differential signals.
Regulatory contextView accessibility, histone, and methylation tracks in mm10.
Tissue contextMap genes and estimated cell-type composition across heart sections.
A useful analysis pattern

Find a gene in Genome Browser, compare its distribution in Gene Expression, inspect its location in Spatial, then review related biology in Pathway Enrichment.

03 · Data orientation

Dataset and experimental terminology

Read the comparison labels literally: the first group is the tested group and the second is the reference group unless a page states otherwise.

TermMeaningWhere you will see it
P1 / P2 / P8Postnatal day at surgery or collection, depending on the source study.Expression, differential analysis, genomic tracks
MIMyocardial infarction induced as the experimental cardiac injury.All injury comparisons
ShamControl surgery performed without induction of myocardial infarction.Reference condition
PSD / dpiPost-surgery day / days post injury; the elapsed time after surgery.Injury datasets and Spatial
P1 vs P8Neonatal/regenerative-stage signal compared with the older reference group.Differential expression and pathways
MI vs ShamInjury-associated signal compared with the matched surgical control.Differential expression and pathways
Check study context before combining results

Age, collection time, assay, normalization, and available cell labels vary by source study. Use each page's dataset note and accession links when interpreting cross-modal agreement.

04 · Tool guide

Genome Browser

Explore an mm10/GRCm38 locus together with condition-level scATAC pseudobulk, optional H3K27ac, methylation references, and gene-level differential-expression cards.

1

Go to a locus

Use the browser search to enter a gene, chromosome interval, or supported identifier. Pan and zoom directly inside the genome viewer.

2

Choose tracks

Open Tracks to use quick views or select individual accessibility, histone, and methylation tracks. Track colors identify P1/P8 and MI/Sham conditions.

3

Retrieve genes

Use Explore chromosome for genes in the visible window, Core genes for curated genes, or Search genes for a comma-separated list.

4

Inspect gene cards

Review fold change and adjusted significance across cell clusters. Open a cluster detail to inspect embedding and metadata views.

Track scales are not interchangeable

Accessibility and H3K27ac represent signal intensity; WGBS represents CpG methylation percentage on a 0–100% scale. A high methylation value should not be interpreted as high accessibility.

05 · Tool guide

Gene Expression

Build a multi-gene distribution plot and keep the filter context of every added gene visible.

Set criteria

Select cell type, surgery, and age group before choosing a gene.

Add genes

Search and add genes one at a time. Each entry retains the criteria used for that query.

Adjust the view

Toggle log scale, split the plot, and show or hide individual x-axis columns.

Reuse queries

Load recent gene/filter combinations again or clear the query history.

“Data points” reports the number of records contributing to that added gene. Distribution width shows density; it is not an additional measure of expression.

1

Select the experiment

Choose MI or Sham, 3 or 7 dpi, and a replicate when more than one section is available. The developmental stage is fixed at P1.

2

Choose the measurement

For gene expression, enter a gene and choose linear or log1p display. For cell composition, select one cell type or display all estimated cell types as spot-level mixtures.

3

Control the tissue view

Toggle histology and spots, tune opacity and spot size, zoom with the toolbar, drag to pan, and double-click to reset the view.

4

Compare and export

Compare samples places MI and Sham side by side at the same timepoint. Compare layers pairs the selected gene and cell-type layer. Download exports the currently visible spot data.

A spot is not a single cell

10x Visium spots may capture RNA from multiple cells. Cell-type values are estimated proportions, and the all-cell view represents mixtures rather than categorical spot labels.

Coordinates and selection

Select a spot to see its barcode, feature value, cell proportions, and high-resolution X/Y coordinates. Spot placement is aligned to each section's histology image.

07 · Tool guide

Pathway Enrichment

Build the view

  1. Choose the biological comparison.
  2. Select one or more cell types.
  3. Set the FDR cutoff and NES range.
  4. Search a pathway and group results by GO or KEGG.
  5. Select a plotted term to inspect its cluster, NES, p-value, and associated genes.
How to read NES
NegativePositive

NES direction follows the comparison shown on the page. Magnitude reflects enrichment strength after normalization; statistical confidence must still be checked with FDR/q-value.

Pathway information and diagram links open the corresponding external GO/BioCyc or KEGG resource when available. Gene links can continue the analysis in Genome Browser.

08 · Tool guide

Search & Download

Filter

Choose file categories, cell types, and PMID values. Multiple selections are supported.

Refine

Use advanced commands such as --comparison=shamvsmi or --group=psd3.

Select

Review the matching table and select one or more rows. The page reports selection count and total size.

Download

Use the download button to retrieve the selected files together.

Large files

Processed matrices and analysis objects can be substantially larger than result tables. Confirm the displayed total size before starting a multi-file download.

10 · Interpretation

Statistical and visual conventions

MeasureInterpretationDo not infer
Log fold change (LFC)Direction and magnitude of change for the displayed comparison.Biological importance from magnitude alone.
Adjusted p-value / FDRMultiple-testing-adjusted evidence against the null model; smaller values provide stronger evidence.Effect size or probability that the hypothesis is true.
−log10(adjusted p)A plotting transform: larger values correspond to smaller adjusted p-values.A different statistical test.
NESNormalized pathway enrichment direction and strength.Significance without checking FDR/q-value.
UMAP / t-SNELow-dimensional views preserving selected aspects of transcriptomic similarity.Literal physical distance, lineage, or developmental time.
Spatial spot valueMeasured expression or estimated cell-type proportion at a capture spot.A measurement from exactly one cell.
